Название программы: Expense Tracker (Трекер расходов)

Описание программы
Expense Tracker — это графическое приложение для учёта личных расходов с возможностью фильтрации и подсчёта суммы за выбранный период. Программа позволяет:
1. добавлять расходы с указанием суммы, категории и даты;
2. просматривать все расходы в виде таблицы;
3. фильтровать записи по категории и периоду;
4. подсчитывать общую сумму расходов за выбранный период;
5. сохранять данные в JSON‑файл и загружать их при следующем запуске.

Используемые технологии:
Python 3.8+;
Tkinter (графический интерфейс);
JSON (хранение данных).

Как использовать
Установка и запуск
Убедитесь, что у вас установлен Python 3.8 или выше.
Скачайте или клонируйте репозиторий:
bash
git clone <ссылка_на_репозиторий>

Перейдите в папку проекта:
bash
cd expense-tracker

Запустите приложение:
bash
python expense_tracker.py

Интерфейс программы
Форма добавления расхода:
Сумма — введите положительное число.
Категория — выберите из выпадающего списка (Еда, Транспорт, Развлечения, Жильё, Одежда, Другое).
Дата — укажите в формате ГГГГ‑ММ‑ДД (по умолчанию — текущая дата).
Нажмите кнопку «Добавить расход», чтобы сохранить запись.
Таблица расходов — отображает все добавленные записи (ID, сумма, категория, дата).

Панель фильтрации:
Фильтр по категории — выберите категорию или «Все».
Период с/по — укажите диапазон дат в формате ГГГГ‑ММ‑ДД.
Нажмите «Применить фильтр» для обновления таблицы и пересчёта суммы.
«Сбросить фильтр» — возвращает к просмотру всех записей.
Статистика — строка «Общая сумма: X руб.» показывает итог по отфильтрованным записям.

Кнопки управления:
«Сохранить данные» — сохраняет все расходы в файл expenses.json.
«Загрузить данные» — загружает записи из expenses.json (автоматически при запуске).

Примеры использования
Пример 1. Добавление расхода
В поле «Сумма» введите 1500.
Выберите категорию «Еда».
Оставьте дату по умолчанию или измените на нужную.
Нажмите «Добавить расход».
Запись появится в таблице, общая сумма обновится.

Пример 2. Фильтрация по категории
Выберите в фильтре «Категория» значение «Транспорт».
Нажмите «Применить фильтр».
Таблица покажет только расходы на транспорт, сумма пересчитается.

Пример 3. Фильтрация по периоду
Введите в поле «Период с» дату 2024-01-01.
Введите в поле «по» дату 2024-01-31.
Нажмите «Применить фильтр».
Отобразятся расходы за январь 2024 года.

Пример 4. Сохранение и загрузка данных
Добавьте несколько расходов.
Нажмите «Сохранить данные». Файл expenses.json создастся в папке проекта.
Закройте и снова откройте приложение.
Данные автоматически загрузятся из файла.
Возможные тесты

Тест 1. Валидация ввода суммы
Введите отрицательное число (−500) → должно появиться сообщение об ошибке.
Введите текст («сто») → должно появиться сообщение об ошибке.

Тест 2. Валидация даты
Введите дату в неверном формате (01-01-2024) → должно появиться сообщение об ошибке.
Оставьте поле даты пустым → должна подставиться текущая дата.

Тест 3. Фильтрация
Добавьте расходы с разными категориями и датами.
Примените фильтр по категории → убедитесь, что отображаются только нужные записи.
Примените фильтр по периоду → проверьте корректность отображения и суммы.

Тест 4. Сохранение/загрузка
Добавьте 3–5 расходов.
Сохраните данные.
Закройте приложение, откройте заново → убедитесь, что записи загрузились.
